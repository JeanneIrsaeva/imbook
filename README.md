# Иммерсивный книжный трекер

Учебный проект по дисциплинам «УПД-2» и «УПД-3», ТУСУР, каф. АОИ, гр. 423-1.

**Автор:** Ирсаева Ж.Р.
**Руководитель:** ст. преподаватель Кульшин Р.С.

## О проекте

Веб-платформа для каталогизации личной библиотеки, трекинга прогресса чтения
и иммерсивного взаимодействия с персонажами книг через ИИ.
